# Logo

Since the HTMLify logo is just a square, it is easy to represent it using Unicode characters.  
Any form of Unicode character that creates a completely filled square can qualify as a logo.

## Logos

### Inline logo

```
■
```

The inline logo uses the Unicode **Black Square** (`U+25A0`).  
It can be used to denote the logo in inline text.


### Inline Big logo

```
██
```

This inline logo is made out of two **Full Block** (`U+2588`).
It can be used to denote the logo in inline text.


### Big logo

```
▄▄▄▄
████
▀▀▀▀
```

This logo is made out of **Full Block** (`U+2588`), **Upper Half Bloc** (`U+2580`) and **Lower Half Block** (`U+2584`).
Can be used in big banner.
