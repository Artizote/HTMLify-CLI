# Print Config Subcommand Style

## Print Config single row example

```
$ htmlify print-config 
■ Configs
├────────┬────────┐
│ name   │ value  │
└────────┴────────┘
```

## Print Config multiple rows example

```
$ htmlify print-config 
■ Configs
├────────┬────────┐
│ name1  │ value1 │
├────────┼────────┤
│ name2  │ value2 │
├────────┼────────┤
│ name3  │ value3 │
└────────┴────────┘
```
