# Banner Art

## Main Banner

The banner art is generated using the [Text to ASCII Art Generator](https://patorjk.com/software/taag) with the **Tmplr** font.

Main banner is 4 cell tall and 14 cell wide.

```
┓┏┏┳┓┳┳┓┓ •┏  
┣┫ ┃ ┃┃┃┃ ┓╋┓┏
┛┗ ┻ ┛ ┗┗┛┗┛┗┫
             ┛
```
